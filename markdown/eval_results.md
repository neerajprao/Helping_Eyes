## 6. Book mode on real books

5 photos of real book pages (4 two-page spreads), read with book mode's path (flatten, spine split, deskew, dewarp, page numbers and running title apart, XY-cut order), then grouped into paragraphs by Qwen 3B as book mode does.

- Printed page numbers right: 0/5 (spreads 0/4). The spine was found, and the spread split into its two pages, on 0 of 4 spreads; a spread read as one wide page has its printed page numbers inside the body text, so none is announced.
- No page in the set has a running title.
- The model grouped the paragraphs on 0 of 5 pages; on the others Qwen 3B did not answer within the app's 12-second limit, so the page was read in layout order, as book mode does.
- Reading starts at the first body line: layout 4/5, with the model's paragraphs 0/0.
- Key lines in the right order (pairs): layout 98.4 %, with the model's paragraphs –.
- Page-turn video: 29.8 s, 4 turns, fed at 8 frames a second: 6 pages read for 5 shown (0 missed, 1 extra), 0 "moved" events (the same page shifted, which does not restart reading).
- Checked by eye (`eval/results/book_video_review.json`): every turn was caught; the one extra read came at 17.3 s, while the hand was still over the page in the middle of a turn, so book mode would have started reading a half-covered page.

## Limits

- **Reference:** Claude's reading of each photo, not a typed ground truth checked by a second person. Where it misread a pack, an engine or answer is marked wrong for it.
- **Small, author-collected set:** photos by one person in one home, most of them medicine packs; confidence intervals (95 % bootstrap over photos) are wide, per-category ones very wide. Not a benchmark.
- **Free-text answers** are judged on a sample, by one judge, drawn from the photos both models had answered when the sample was taken; factual answers are scored by fixed rules, which were checked by hand on random samples and are themselves tested (`eval/test_scoring.py`).
- **The strength question also says "dose"**: on a pack with no printed strength, an answer that quotes the dosing directions is scored wrong. This is rare and affects both models alike.
- **Seen while judging:** once, Qwen put the app's hidden `[NOT_IN_TEXT]` tag in the middle of an answer, where the app does not remove it, so it would be spoken.
- **Gemini is a hosted model** that can change, and its speed depends on its load on the day; the run date and model name are recorded in the result files.
- **Speed** is measured on localhost: the network to a phone, the browser's camera and JPEG work, speech recognition and audio start are not included.
- **Prompts were not tuned on these photos**; the app was frozen before the runs (the commit and whether the tree had uncommitted changes are in every result file).
